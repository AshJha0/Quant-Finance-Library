quantfinlib

A Java library for quantitative finance research and risk, using only the JDK at runtime, with a reference low-latency trading lane.

Version 2.0.0 · Java 25 · MIT licence · Source on GitHub

What it covers

AreaPackagesExamples

Install

From JitPack:

<repository>
  <id>jitpack.io</id>
  <url>https://jitpack.io</url>
</repository>

<dependency>
  <groupId>com.github.AshJha0</groupId>
  <artifactId>Quant-Finance-Library</artifactId>
  <version>v2.0.0</version>
</dependency>

Or build from source with a JDK 25:

git clone https://github.com/AshJha0/Quant-Finance-Library.git
cd Quant-Finance-Library
./mvnw verify

Not implemented

  • Multi-curve (OIS and projection) bootstrapping
  • The ISDA CDS standard model
  • SA-CCR, SIMM and the FRTB standardised approach
  • SVI surfaces and local volatility
  • FIX session schedules and FIX versions other than 4.4
  • Live venue connectivity and certification
quantfinlib is released under the MIT licence. The trading lane is a reference implementation, not a certified trading system.
