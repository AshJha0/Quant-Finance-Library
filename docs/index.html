quantfinlib

A Java library for quantitative finance research and risk, using only the JDK at runtime, with a reference low-latency trading lane.

Version 3.0.0 · Java 25 · MIT licence · Source on GitHub

What it covers

AreaPackagesExamples
Pricingpricing, fxBlack-Scholes-Merton, Black-76, Bachelier, implied volatility, Heston (COS, calibration), SABR, SVI and SSVI, Dupire local volatility, barriers, touches, Asian, quanto, vanna-volga, FX volatility surface
Rates and creditrates, creditMulti-curve OIS bootstrap with DV01, street-convention bonds, swaps, swaptions, caps, day counts, ISDA CDS model with holiday calendars and the swap-only ISDA rate curve, single- and multi-currency exposure simulation with foreign-currency swaps and a stochastic basis, CVA, bilateral and wrong-way CVA, Z-spread

Install

From JitPack:

<repository>
  <id>jitpack.io</id>
  <url>https://jitpack.io</url>
</repository>

<!-- stable tier only -->
<dependency>
  <groupId>com.github.AshJha0.Quant-Finance-Library</groupId>
  <artifactId>quant-finance-library</artifactId>
  <version>v3.0.0</version>
</dependency>

<!-- or the trading lane, which brings the stable tier with it -->
<dependency>
  <groupId>com.github.AshJha0.Quant-Finance-Library</groupId>
  <artifactId>quant-finance-library-lowlatency</artifactId>
  <version>v3.0.0</version>
</dependency>

Or build from source with a JDK 25:

git clone https://github.com/AshJha0/Quant-Finance-Library.git
cd Quant-Finance-Library
./mvnw verify

Not implemented

  • ISDA SIMM: not included; ISDA licenses SIMM for use
  • FRTB SA certification; SEC-IRBA weights in the securitisation default risk charge
  • SA-CCR haircuts for funds (CRE22.50 fund rule)
  • Stochastic basis for foreign-currency swaps
  • Certification of the CAT and EMIR reports; MiFIR rules CON-330, CON-331 and CON-430 and the pending workflow
  • Live venue connectivity and certification
quantfinlib is released under the MIT licence. The trading lane is a reference implementation, not a certified trading system.
